# Obsidian & Ember — Procedural UI Specification v1.0

Статус: проектная спецификация для утверждённого макета RPG Inventory & Shop. Все значения — целевые параметры реализации, не точные замеры с растрового референса.

## 1. Базовые правила
- Целевой Canvas: 1920×1080, Scale With Screen Size, Match Width Or Height = 0.5.
- Цвета в sRGB HEX. Alpha в таблицах указан отдельно как доля 0–1.
- Градиент: линейная интерполяция между stop 0 (верх) и stop 1 (низ), если не указано иначе.
- Радиусы, толщина рамок, размеры и blur указаны в reference pixels Canvas.
- У всех поверхностей нет орнаментов и запечённого текста.
- Для точных радиусов/границ — SDF rounded rectangle в UI shader; мягкие тени — отдельный SDF-проход/слой, не текстура.
- Толщина рамки измеряется внутрь от внешнего контура, чтобы не менять layout.
- Прозрачность применяется к цвету соответствующего слоя, а не ко всему CanvasGroup (иначе текст тоже потускнеет).

## 9. Текст
- Заголовки: Ivory #F0E6D6; основной текст Ivory; вторичный Muted Text #A6A9B0.
- Золото и активная цена: Ember #C58D59; HP: Ivory + Blood bar.
- Предпочтительно TMP с единым семейством шрифтов: выразительный serif для заголовков, хорошо читаемый serif/sans для UI-значений. Конкретные лицензированные шрифты выбрать отдельно.
- Текст никогда не запекается в фоновые спрайты.

## 10. Процедурная реализация Unity
- uGUI `Graphic`/`MaskableGraphic` с собственным shader для SDF rounded rectangle: `_Radius`, `_BorderWidth`, `_BorderColor`, `_FillTop`, `_FillBottom`, `_FillAlphaTop`, `_FillAlphaBottom`, `_GlowColor`, `_GlowWidth`.
- Для независимых настроек каждого UI-элемента предпочтительнее кастомный `MaskableGraphic` с параметрами через vertex data или управляемые экземпляры материалов; избегать случайного создания нового Material каждый кадр.
- Обеспечить поддержку CanvasRenderer, RectMask2D/Mask, stencil, UI clipping и корректный alpha blending; проверить в URP 2D и Player Build.
- Для теней и glow допустим отдельный процедурный слой; не применять blur по всему Canvas.
- У всех компонентов должно быть общее theme/token source; не размножать HEX в коде.
- Сначала один демонстрационный компонент с idle/hover/selected и корректным masking, затем масштабирование на весь UI.

## 11. Что НЕ генерировать как текстуры
Panel backgrounds, borders, slots, hover, selected, buttons, HP bars, dividers, tooltip — всё процедурно.

## 12. Что остаётся текстурными ассетами
Иконки предметов, золота, инвентаря/магазина и необязательный атмосферный задний фон. Утверждённый общий мокап — только reference, не цельная текстура UI.
